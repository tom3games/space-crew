# 宇宙船クルー

全員で1隻の宇宙船を動かし、危険な宙域を抜けて目的地のビーコンまで運ぶ協力ゲーム。担当ごとに操作盤が違い、危険地帯が見えるのはナビだけ。声を掛け合わないと着かない。

- 人数: おすすめ3〜8人（1〜2人でも遊べる。兼任になる）
- 1プレイ: 発進前の担当確認4秒＋航行最大150秒
- 手元のポート: 8106

## 遊び方

1. ホストが部屋を作り、招待URL（/r/コード）を送る。みんなはニックネームを入れて参加
2. 「発進準備」を押すと担当が配られ、4秒間その説明が出る
3. 船を目的地（緑の輪）まで運べば勝ち

| 担当 | 操作 | 見えるもの |
|---|---|---|
| 操縦 | 左右のボタン（押す間だけ曲がる） | 前方の景色、近くの隕石、目的地の方向、ナビの目印。**危険地帯は見えない** |
| エンジン | 出力4段（停止・低速・巡航・全開）、冷却 | 速度、熱、電力 |
| 修理 | 壊れた装置をタップ連打 | 5つの装置の状態 |
| ナビ | 地図をタップして目印を置く | **航路全体の地図と、岩場・電磁嵐** |
| 防衛 | レーダーをタップした方向に撃つ | 遠くまでの隕石 |

全員が見えるもの: 船体・電力・酸素、目的地までの距離、残り時間、故障中の装置、掛け声。
故障の札をタップすると「○○を修理して」と全員に出る。担当ごとの掛け声ボタン（左へ・減速して・隕石が来る など）もある。

### 人数ごとの担当

| 人数 | 担当 |
|---|---|
| 1 | 1人で全部 |
| 2 | 操縦+エンジン / ナビ+修理+防衛 |
| 3 | 操縦+エンジン / ナビ+防衛 / 修理 |
| 4 | 操縦 / エンジン+修理 / ナビ / 防衛 |
| 5 | 1人1担当 |
| 6〜8 | 5担当＋修理と防衛を増やす（6: 修理2、7: 修理2・防衛2、8: 修理3・防衛2） |

並びは毎回混ぜるので、再戦すると担当が変わる。途中で抜けた人の担当は、担当の少ない人に引き継がれる。

## ルール

- **勝ち**: 目的地から半径200以内に入る。星は船体40以上で2つ、船体75以上かつ残り30秒以上で3つ
- **負け**: 船体0（大破）／酸素0／150秒たっても着かない
- **故障**（操舵装置・エンジン・センサー・砲台・生命維持）: 勝手に起きる（人数が多いほど起きやすい）。隕石が当たったとき、電磁嵐の中、エンジンの過熱でも起きる。修理のタップ12回で直る
  - 操舵装置: 舵が効かず勝手に少しずつ曲がる / エンジン: 速度が20まで落ちる / センサー: ナビの地図が消え目印も置けない / 砲台: 撃てない / 生命維持: 酸素が毎秒3.5減る
- **岩場**: 中にいる間、船体が削れる（速いほど多く）。**電磁嵐**: 電力が減り、故障しやすい。**航路の外**: 船体が削れる
- **電力**: 毎秒4回復。出力が高いほど使う。1発6、冷却12。0になると低速までしか出ない
- **熱**: 全開で毎秒9たまり、100でエンジン故障。巡航ではゆっくりたまり、低速・停止で冷える
- 全部は直せない。何から直すか、どこを通るかを決めるのがこのゲームの判断

## 起動

```
npm install
npm start
```

ブラウザで http://localhost:8106 を開く。別のポートは `PORT=8080 npm start`。

## テスト

```
npm test               # ルールの単体テスト・ルーム管理・WebSocket の統合テスト（41件）
node tools/e2e.mjs     # 実ブラウザ（chromium と webkit）で3人つないで、担当確認→航行→到着→再戦まで通す
node tools/make-og.mjs # og.png を描き直す
```

e2e は短いコース（距離1800）をサーバー側の設定で使い、各ページが自分の担当の操作盤だけを触って目的地まで運ぶ。390x844 / 360x640 / 844x390 で全画面・全担当の操作盤が一画面に収まるか、コンソールエラーが0件かも確かめる。スクショは `tools/shots/`。

## 仕組み

- 状態はサーバー（`lib/game.mjs`）だけが持つ。物理は内部で1/30秒の固定ステップ、送信は毎秒15回。画面は届いた状態の間を補間して描く
- 担当以外の操作はサーバーが `not_your_role` で拒否する
- 危険地帯の地図はナビの view にだけ、3秒おきに入れる（変わらないので毎回は送らない）。隕石は操縦と防衛の view にだけ入る
- `startServer({ gameOpts })` でコースの長さなどをサーバー側から変えられる。画面から届いた設定は使わない
- index.html を返すとき、og:image を届いた Host から絶対URLに書き換える

- 防衛の当てやすさ・故障の頻度は、実際に人が遊んだ結果で調整する（いまはボットの試算で、完璧に動けば9割着く・修理と防衛をさぼると必ず負ける程度）

- 担当ごとの効果音と、到着時の演出をもっと派手にする
